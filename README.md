## quickstart

requires `node` and `bun`

  ```bash
  # clone the repo
  git clone https://github.com/KingJayan/dev-portfolio.git
  cd dev-portfolio
  ```

  ```bash
  bun i # install deps
  bun dev # run locally
  bun build # build prod bundle
  ```
